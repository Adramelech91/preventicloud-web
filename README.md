# PreventiCloud WebApp — repository pubblico

Questo repository contiene **solo il build statico** della WebApp PreventiCloud.
Il sorgente completo, il backend e i segreti restano nel repository privato.

Dominio previsto: `https://preventicloud.instant3d.org`

Il workflow `.github/workflows/pages.yml` pubblica automaticamente il contenuto del branch `main` su GitHub Pages.
